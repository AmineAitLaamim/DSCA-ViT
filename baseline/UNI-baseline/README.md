# UNI Baseline — HER2-IHC-40x

A plain baseline using the **UNI histopathology foundation model**
(ViT-L/16, DINOv2, mass100k) as backbone, trained/evaluated with the
**same proper protocol** as the plain ViT-B16 baseline (`baseline/`).

The goal is to test whether UNI alone beats:

| Model | Test accuracy |
|-------|---------------|
| Proper ViT-B16 baseline | **94.69%** |
| DSS-ViT v2.2 | **93.18%** |
| UNI baseline (this) | TBD |

---

## 1. Model

| Item | Value |
|------|-------|
| Task | HER2 IHC breast cancer grading (4 classes) |
| Classes | `class_0`, `class_1+`, `class_2+`, `class_3+` |
| Backbone | UNI — `vit_large_patch16_224` (DINOv2, mass100k) |
| Head | Linear 1024 -> 4 |
| Input | 224×224 RGB raw [0,1] (model normalizes internally) |
| Checkpoint | Strict local load, no network |

### 2-stage protocol

| Stage | Strategy | Optimizer | LR | Epochs | Scheduler |
|-------|----------|-----------|-----|--------|-----------|
| 1 | Frozen UNI, head only | Adam | 1e-4 | 30 | CosineAnnealingLR |
| 2 | Full fine-tune | Adam | backbone 1e-5, head 1e-4 | 30 | CosineAnnealingLR |

- Loss: CrossEntropyLoss (no label smoothing), Adam, wd 0.0, batch 32,
  AMP off, no clipping.

### Transforms

Train: `Resize((224,224))`, HFlip 0.5, VFlip 0.5, Rotation(10, bilinear,
fill=0), `ToTensor()`.

Val/Test: `Resize((224,224))`, `ToTensor()`.

**No ImageNet normalization in the dataloader** — the model applies it
internally.

## 3. Shared split (IMPORTANT)

The UNI baseline **loads only** the WSI-aware split generated by the
proper ViT-B16 baseline. **It never regenerates it.**

```
/home/amine.aitlaamim-ext/projects/DSCA-ViT/
  experiments/ViT-Baseline/plain_vit_baseline_001/split_indices_wsi.npz
```

| Key | Value |
|-----|-------|
| `train_indices` | 7,283 |
| `val_indices` | 810 |
| `test_indices` | 1,847 |
| `val_fraction` | 0.10 |
| `seed` | 42 |

`load_split_indices()` in `train_uni_baseline.py` **raises if the file is
missing**, so a wrong/old split can never be used silently.

## 4. Commands

```bash
# Debug / sanity check
uv run python baseline/UNI-baseline/train_uni_baseline.py \
    --config configs/uni_baseline_config.yaml --debug

# Train on HPC
sbatch slurm/slurm_uni_baseline/train_uni_baseline.slurm

# Resume
uv run python baseline/UNI-baseline/train_uni_baseline.py \
    --config configs/uni_baseline_config.yaml --resume

# Evaluate (loads best_stage2.pt, never last.pt)
sbatch slurm/slurm_uni_baseline/evaluate_uni_baseline.slurm
```

### `--debug` does

- Sets `HF_HUB_OFFLINE=1` at the very top before any imports.
- Static-scans `baseline/UNI-baseline/` for
  `hf_hub_download`, `huggingface_hub.login`, `HF_TOKEN`,
  `from_pretrained` and raises if found.
- Random raw-RGB batch [B,3,224,224] in [0,1]; checks logits/probs
  [B,4] shapes, `loss.backward()`, no NaN/Inf, prints param counts.
